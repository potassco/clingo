◆ condition_id()

auto Clingo::TheoryElement::condition_id ( ) const -> std::optional<ProgramLiteral>
inlinenodiscard

Get a program literal for the condition of the theory element.

True conditions do not have a condition id, in which case std::nullopt is returned. A condition id is only valid for the current solving step.

A condition id can be mapped to a solver literal using Clingo::PropagateInit::solver_literal().

Returns
the condition id as a program literal
