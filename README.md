# Documentation Branch

This branch contains the versioned documentation for the clingo C and Python
APIs.

Documentation is automatically published when changes are pushed to this
branch.

## Structure

- `clingo/c-api/` - Documentation for the C API
- `clingo/python-api/` - Documentation for the Python API

Each subdirectory contains the documentation for a specific release. The
`current` symlink points to the latest recommended version.

This branch is intended to host documentation only. Source code and development
happen on the master and wip project branches.
