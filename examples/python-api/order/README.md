## Example: Predictable Program Printer

This script prints logic programs in a more predictable format by ordering rule
bodies and statements. It is useful for applying diffs to programs with small
differences.

### Features

- Orders bodies of rules for consistent output
- Parses and prints statements from input files

### Usage

```bash
python example.py <input-file1.lp> <input-file2.lp> ...
```
